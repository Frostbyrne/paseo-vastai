# paseo-vastai

A [Paseo](https://paseo.sh) plugin that shows your Vast.ai GPU instances, hourly cost and remaining credit in the sidebar, and lets you stop or destroy them. See [OVERVIEW.md](OVERVIEW.md) for what it does and what it sends where.

Development: `npm install`, `npm run typecheck`, then `paseo plugin reload paseo-vastai` after edits.
